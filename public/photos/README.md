# Фотографии сайта

Положите сюда 3 реальных фото с ТОЧНО такими именами:

| Файл       | Что на фото                          | Куда идёт              | Реком. размер |
|------------|--------------------------------------|------------------------|---------------|
| hero.jpg   | Девочки играют за столом (мяч)        | Главный экран (Hero)   | ~1200×1500 (портрет 4:5) |
| about.jpg  | Мальчики/дети пишут за столом         | Блок «О студии»        | ~1000×750 (4:3) |
| class.jpg  | Девочка пишет у доски / занятие       | «Как проходят занятия» | ~1600×900 (16:9) |

Форматы: jpg / webp / avif. Пока файлов нет — на их месте показывается
аккуратный фирменный блок-заглушка (не «битая картинка»).
