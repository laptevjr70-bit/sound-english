# Sound English — Лендинг детской студии английского

Одностраничный лендинг для детской студии английского языка **Sound English** (Воронеж).

## Стек

- **Next.js 16** (App Router) + TypeScript strict
- **Tailwind CSS v4** — CSS-переменные для цветов и типографики
- **Motion** (`motion/react`) — анимации компонентов
- **GSAP + ScrollTrigger** — scroll-анимации, reveal, count-up
- **Lenis** — плавный скролл, синхронизирован с GSAP
- **Radix UI** — базовые компоненты (Accordion, Checkbox, Select и др.)
- **react-hook-form + zod** — типизированная валидация формы
- **Sonner** — toast-уведомления

## Запуск

```bash
npm install
npm run dev
# → http://localhost:3000
```

Продакшн-сборка:
```bash
npm run build
npm start
```

## Где менять тексты

**Все тексты секций** — в одном файле:
```
src/lib/content.ts
```
Здесь хранятся: контакты, навигация, тексты hero, программы, FAQ, отзывы и т.д. Клиент может редактировать только этот файл, не трогая разметку.

**Политика конфиденциальности** (текст с плейсхолдерами):
```
src/lib/privacyContent.ts
```
Найдите все `[ЗАПОЛНИТЬ]` и заполните реквизитами.

## Соответствие 152-ФЗ — что нужно сделать до запуска

Технически сайт уже соответствует требованиям: есть страница /privacy, cookie-баннер
и отдельный чекбокс согласия по нормам от 01.09.2025.

### Обязательные шаги перед запуском:

1. **Заполнить реквизиты в политике.**
   Открыть `src/lib/privacyContent.ts`, найти все `[ЗАПОЛНИТЬ]`
   и вписать: полное наименование ИП/ООО, ОГРН/ОГРНИП, ИНН,
   юридический адрес, email для обращений по ПДн, дату публикации,
   домен сайта, хостинг (должен быть в РФ), перечень используемых
   аналитических сервисов.

2. **Подать уведомление в Роскомнадзор.**
   До начала обработки ПДн — обязательно (ст. 22 152-ФЗ).
   Портал: https://pd.rkn.gov.ru
   После получения номера — вписать его в политику (раздел 10).

3. **Убедиться, что хостинг/база данных находятся в РФ** (ч. 5 ст. 18 152-ФЗ).

4. **Настроить аналитику условно.**
   В `CookieConsent.tsx` в TODO-блоке подключить Яндекс.Метрику
   только при consent === 'all'. При consent === 'necessary' —
   счётчик не инициализировать.

5. **Настроить лог согласий.**
   При реальной отправке формы сохранять
   `{ name, phone, consentGivenAt, ipHash }` на стороне сервера.

6. **Проверить текст политики с юристом** — особенно разделы
   о целях, основаниях обработки и сроках хранения.

Штрафы за нарушение (актуально с 30.05.2025): до 25 млн ₽ для
организаций (ч. 10 ст. 13.11 КоАП РФ в ред. 2025 г.).
